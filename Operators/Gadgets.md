# Gadget System

Kiekvienas operatorius turi **vieną unikalų gadgetą**, priklausantį nuo jo **primary role** ir **pusės (ATK/DEF)**.  
Gadgetai yra **pririšti prie role** – negalima turėti kitos role'o gadgeto.  
Principas panašus į Rainbow Six Siege: role nustato gadgeto tipą, o unikalumas nustato konkrečią mechaniką.

---

## 🔴 ATK Gadgets

### Entry
> Tikslas: pralaužti defense, pirmas įeiti, dominuoti close fight'uose.

| Gadgetas | Efektas |
|----------|---------|
| Breaching Charge | pramušia sieną / duris, atveria naują entry point |
| Flashbang | apakina priešus prieš entry |
| Stun Grenade | dezorientuoja, sumažina reaction ir decision making |
| Hard Breach Kit | lėtesnis bet tylus pralaužimas, nesukelia garso |

---

### Second Entry
> Tikslas: seka entry, tradina killus, išnaudoja chaos'ą.

| Gadgetas | Efektas |
|----------|---------|

| Smoke Grenade | uždaro kambario sight lines, saugesnis push |

### Support
> Tikslas: info, cover, stabilumo palaikymas visam squad'ui.

|----------|---------|

### Utility Specialist
> Tikslas: neutralizuoti DEF gadgetus, kontroliuoti erdvę.

| Gadgetas | Efektas |
|----------|---------|
| EMP Grenade | išjungia elektroninius DEF gadgetus (kameras, trap'us) |

| Gadget Detector | parodo kur DEF dėjo gadgetus prieš entry |

---

### Flex
> Tikslas: prisitaikyti prie situacijos – gali naudoti ribotą kiekį iš kelių kategorijų.

| Gadgetas | Efektas |
|----------|---------|
| Multi-Tool Kit | vienas charge iš Entry arba Utility pool |
| Adaptive Smoke | gali naudoti tiek kaip cover tiek kaip distrakcija |
| Scout Drone | lengvesnis nei Support drone, bet greičiau deployinamas |

> ⚠️ Flex gauna **mažiau efektyvias** versijas – kompromisas už lankstumą.

## 🔒 Role lock taisyklės

| Taisyklė | Aprašymas |
|----------|-----------|
| **Primary role = gadget pool** | Operatorius renkasi tik iš savo primary role gadgetų |
| **Secondary role = 1 bonus** | Secondary role suteikia prieigą prie **vieno** gadgeto iš tos role pool'o |
| **Cross-side draudimas** | ATK operatorius negali turėti DEF gadgetų ir atvirkščiai |
| **Unikalumas** | Kiekvienas operatorius turi vieną fiksuotą gadgetą – jo "signature" |

### Pavyzdys

**Operatorius: "Viper"**
- Side: ATK · Primary: Entry → **Breaching Charge**
- Secondary: Flex → papildomai **Scout Drone**

**Operatorius: "Ghost"**
- Side: DEF · Primary: Roamer → **Decoy Device**
- Secondary: Lurker → papildomai **Flank Wire**

## 🟢 Simplified versija (MVP)

Pirmai versijai nereikia visų gadgetų. Kiekvienai role **vienas gadgetas** – paprasčiausias ir aiškiausias.

| Role | Side | MVP Gadgetas | Kodėl |
|------|------|-------------|-------|
| Entry | ATK | Breaching Charge | Pagrindinis entry mechanikas |
| Second Entry | ATK | Smoke Grenade | Paprastas, aiškus efektas |
| Support | ATK | Drone | Info mechanikas – svarbus visam match'ui |
| Utility Specialist | ATK | EMP Grenade | Anti-gadget – kontroja DEF setup'ą |
| Flex | ATK | Scout Drone | Universalus, nesudėtingas |
| Anchor | DEF | Reinforcement Panel | Pagrindinis DEF setup mechanikas |
| Roamer | DEF | Proximity Alarm | Paprastas info tool roameriui |
| Lurker | DEF | Flank Wire | Vienas trap'as – lengva implementuoti |
| Trap Specialist | DEF | Barbed Wire | Paprasčiausias trap mechanikas |
| Support Defender | DEF | Camera Network | Info sistema – svarbus DEF pusės |

> 💡 MVP tikslas: **1 gadgetas per role**, kuris aiškiai paveikia round simuliaciją. Visi kiti gadgetai pridedami vėliau kaip operator unikalumas.

### MVP implementation

- Each gadget is `{ class, tier }` in `demo/data.js`. `GADGETS[class]` gives a flat bonus per situation (Info, Breach, Utility, Reposition, Gunfight, Objective, Clutch); the Info value is the intel bonus. Table: Formula.md §15.1.
- **Tier is a multiplier** on that situation value (`GADGET_TIER_MULT`): × 1.00 / 1.03 / 1.06 / 1.09 / 1.12 / 1.15 for tiers 1–6. A gadget worth 0 in a situation stays 0 at any tier. The MVP roster is tier 1 (× 1.00). This answers the upgrade question above for the MVP: an upgrade is a tier.
- Space type then multiplies by 0.90 / 1.00 / 1.10 (Narrow, Open, Fortified, Connector; Formula.md §15.2).
- Charges (one-use gadgets) are not implemented: a gadget adds its bonus in every step. Utility Handling does not scale the gadget bonus directly; it only enters through the situation weights.
- In the Entry step the gadget-support roles (Utility Specialist, Support Defender) add only their gadget bonus (Formula.md §9).
